# 🌧️ Dashboard de Controle Pluviométrico — Excel

Dashboard desenvolvido no **Microsoft Excel** para monitoramento e análise de dados pluviométricos de duas estruturas, permitindo acompanhar os índices de precipitação, comparar períodos e identificar variações no volume de chuvas.

O projeto apresenta indicadores visuais e gráficos comparativos para facilitar o acompanhamento mensal e acumulado da precipitação, contribuindo para uma análise mais clara dos dados de monitoramento geotécnico.

## 🎯 Objetivo do Projeto

Desenvolver um painel de controle pluviométrico capaz de consolidar dados de chuva, comparar os resultados entre 2025 e 2026 e destacar informações relevantes para o acompanhamento das estruturas monitoradas.

## 📊 Indicadores do Dashboard

- **Acumulado de Precipitação (mm):** acompanhamento do volume acumulado de chuvas em cada estrutura.
- **Média Mensal:** comparação das médias mensais entre 2025 e 2026.
- **Maior Precipitação:** identificação do mês com maior volume de chuva em cada ano.
- **Variação Percentual:** análise do crescimento ou da redução da precipitação acumulada em relação ao ano anterior.
- **Pluviometria Mensal:** comparação dos volumes de chuva registrados mês a mês.

## 📈 Análises Desenvolvidas

- **Comparativo Anual:** análise da precipitação entre 2025 e 2026.
- **Monitoramento por Estrutura:** acompanhamento individual dos dados pluviométricos das duas estruturas.
- **Evolução Mensal:** visualização do comportamento das chuvas ao longo dos meses.
- **Destaques Analíticos:** identificação dos períodos de maior precipitação e das principais variações.
- **Acompanhamento Acumulado:** comparação dos volumes registrados em cada estrutura durante o período monitorado.

## 🛠️ Ferramentas e Tecnologias

- Microsoft Excel
- Gráficos e visualização de dados
- Indicadores de desempenho (KPIs)
- Análise comparativa de dados
- Monitoramento pluviométrico

## 💡 Resultados e Aplicações

O dashboard consolida informações pluviométricas em uma única interface, facilitando a leitura dos dados, a comparação entre estruturas e o acompanhamento das variações de precipitação.

A organização visual dos indicadores permite identificar rapidamente os meses com maiores volumes de chuva e acompanhar a evolução dos acumulados em relação ao ano anterior.

O projeto demonstra como o Excel pode ser utilizado para estruturar dados de monitoramento e transformá-los em informações visuais úteis para o acompanhamento operacional.
